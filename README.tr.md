# YTMusic Widgets

GitHub Profiliniz için gerçek zamanlı YouTube Music durum widget'ı.

![Status](https://widgets.erslly.dev/widgets/815668704435896321&theme=elite)

## Özellikler

- **Gerçek Zamanlı**: Özel Presence API ile şarkı verileri anında güncellenir.
- **Şık Temalar**: Profil estetiğinize uygun birden fazla tema.

## Kullanım

Bunu README dosyanıza kopyalayıp yapıştırın:

```markdown
![YouTube Music](https://widgets.erslly.dev/widgets/YOUR_DISCORD_ID&theme=elite)
```

### Seçenekler
- `id`: Discord Kullanıcı ID'niz (Zorunlu).
- `theme`: `classic`, `elite` veya `glass` (Varsayılan: `classic`).


> [!NOTE]
> Bunun çalışması için [Discord](https://discord.gg/kBwAjuwuds) sunucusunda olduğunuzdan emin olun.

## Teşekkürler

**Classic** ve **Elite** tema tasarımlarına ilham verdiği için [luluwux/Spotify-Github-Profile](https://github.com/luluwux/Spotify-Github-Profile)'a özel teşekkürler.
